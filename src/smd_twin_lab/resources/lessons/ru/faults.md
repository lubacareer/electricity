# Задавайте неисправности явно

Сценарий неисправности изменяет созданную для моделирования копию и никогда не должен изменять
исходный проект.

- **Обрыв компонента:** разрывает один смоделированный путь тока.
- **Короткое замыкание цепей:** добавляет между двумя именованными цепями путь с конечным малым сопротивлением.
- **Неверный номинал:** изменяет параметр компонента на документированное значение.
- **Обратная полярность:** подставляет утверждённую модель обратной установки.
- **Периодический обрыв:** включает неисправность в точно заданные моменты виртуального времени.

Начинайте с одной неисправности. Сохраняйте в отчёте её цель, значение, время начала, температуру,
версию симулятора и допущения модели. Буквально нулевое сопротивление короткого замыкания и
бесконечное сопротивление обрыва часто вызывают численные проблемы, поэтому модели должны
использовать документированные конечные значения.
